TRANSPARENCY

What the numbers mean

Built to distinguish measured stats from model estimates.

EPA per play

Expected Points Added measures how much a play changes a team's expected points, using nflverse play-by-play EPA when available.

Success rate

Share of plays with positive EPA when the feed includes EPA. This is a useful efficiency measure, not a measure of explosive plays alone.

Risk-worthy throws

There is no universal official NFL statistic with this name. NFL Edge does not pretend to have a proprietary charting grade. Where play-by-play supports it, interception-worthy outcomes can be shown as a limited proxy; this is not equivalent to charted risky throws.

Pressure rate

Pressure rate requires dependable pass-rush charting. When pressure fields are missing, the dashboard leaves the metric unavailable rather than inventing a precise-looking value. Sacks are not a valid substitute for all pressures.

Predictions

Win probability uses an intentionally simple, explainable logistic model based on team scoring margin and EPA/play, with a modest home-field adjustment. It can pick an underdog when the metrics justify it.

Refresh cadence

GitHub Actions downloads upstream data on a schedule and commits a static JSON package. This is automatically refreshed data, not a second-by-second live play feed. Refresh can also be triggered manually in GitHub Actions.
